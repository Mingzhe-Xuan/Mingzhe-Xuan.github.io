# Xuan Mingzhe — Academic Homepage

Building intelligence towards the future.

GitHub Pages address: [mingzhe-xuan.github.io](https://mingzhe-xuan.github.io/)

Personal academic homepage for Xuan Mingzhe, a Statistics undergraduate at the University of Science and Technology of China. Current interests include AI4Material and LLM Agents, with an open interest in new directions.

## Local preview

Open `index.html` directly, or run:

```sh
npm run dev
```

Then visit http://127.0.0.1:4174/. No dependency installation or build step is required.

## Update content

- `content.js`: profile, GitHub, announcement, news, research, experience, and acknowledgements.
- `index.html`: fixed section headings, research vision, and profile labels.
- `styles.css`: responsive layout and colors.
- `assets/`: portrait, research figures, original figure PDF, and CV.

The announcement editor appears only in local preview. Its drafts stay in the local browser. Download the updated `content.js` and replace the project file to make a draft part of the website.

```sh
npm run check
```

## GitHub Pages

Repository: `Mingzhe-Xuan/Mingzhe-Xuan.github.io`.
Publish the `main` branch from `/` using GitHub Pages. `.nojekyll` is included because the site uses plain HTML, CSS, and JavaScript. Site assets use relative paths.

## Sources and design

Research, education, and experience facts come from the owner’s supplied revised CV. Mentor acknowledgements and GitHub identity were confirmed by the owner. The portrait and research figures were supplied by the owner; the original PDFs are preserved.

The page organization and visual reference is [Xuyan Ye’s homepage](https://xuyanye.com/). This site is independently implemented with Xuan Mingzhe’s own content and assets.
